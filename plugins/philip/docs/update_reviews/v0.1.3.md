# Philip Relay v0.1.3 review

Date: 2026-10-11

## 근거

This release promotes the reusable portions of private PSP v2.11.9 after a fresh public-boundary and privacy review.

## 변경 분류

- Promotes reusable changes reviewed through private PSP v2.11.9.
- Stops memory sync from guessing among multiple configured memory folders.
- Refuses index replacements that would hide retained memory files unless explicitly allowed.
- Keeps every Markdown link on multi-link memory-index lines and reports bounded omissions.
- Treats the deletion hook as a mistake-prevention aid, not a security sandbox.
- Keeps recycle-bin/quarantine deletion as the default while allowing exact, previewed, user-approved permanent deletion through `safe_delete.py --permanent --confirmed-by-user --yes`.
- Allows `git push --force-with-lease` and safe `rsync --delay-updates`, while continuing to block plain force pushes and common destructive commands.

## 공개 경계

- Replaces a private project slug used in examples with `my_project`.
- Does not copy private profiles, project memory, todo state, private release policy, incident identifiers, or private update reviews.
- Preserves Philip Relay branding and public-only README, license, contribution, security, and packaging files.

## 행동 평가

- Generated skills, unit tests, manifest versions, links, orphan checks, duplicate checks, current-tree privacy checks, and reachable Git-history checks are required before release.
- Windows symbolic-link coverage may be skipped when the current account lacks symbolic-link privileges; all other tests must pass.

## 왜곡 위험

- The command hook intentionally does not parse every nested shell language. It prevents common accidents; explicit user authorization and narrow targets remain the operating boundary.
- `--confirmed-by-user` is an operational assertion by the agent, not cryptographic proof of the conversation. Philip Relay is a mistake-prevention workflow, not a hostile-agent sandbox.

## 미검증

- Fresh Claude and Codex conversational behavior evaluation remains separate from mechanical hook and tool tests.
- Installation from the published v0.1.3 marketplace is verified only after the public commit and tag exist.
