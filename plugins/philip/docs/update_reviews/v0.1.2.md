# Philip Relay v0.1.2 release review

Date: 2026-10-11

## Evidence

- Byte-identical `AGENTS.md` and `CLAUDE.md` files could be reported as divergent when their shared body mentioned both filenames.
- No file was overwritten, but every session could show a false conflict warning.

## Changes

- Treat byte-identical rule files as synchronized before applying host-specific canonicalization.
- Add a regression test whose identical body mentions both filenames.

## Boundary

- Divergent files still take the non-mutating conflict path.
- Explicit edit synchronization still creates a local backup before replacing the counterpart.

## Validation

- Unit tests exercise identical, divergent, and explicit-sync paths separately.
- The public release gate still checks manifests, tags, links, privacy patterns, duplicates, and generated skills.
