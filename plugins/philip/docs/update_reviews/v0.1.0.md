# Philip Relay v0.1.0 공개 릴리스 감사

## 근거

- 범용 행동 매뉴얼, 메모리·검증 도구, 도메인 지식 라우터를 공개 플러그인으로 분리한다.
- 개인 프로젝트 프로필과 상세 게임·웹·연구 지식은 플러그인 밖에 유지한다.
- Claude Code와 Codex에서 동일한 `philip:` 스킬 이름을 사용한다.

## 변경 분류

- 안전 불변식: 파괴 작업 사전 확인, 원격 문서의 실행 권한 분리, 자동 업데이트·자동 push 금지.
- 일반 기본값: 단일 에이전트 우선, 점진적 컨텍스트 회수, 감사와 수정 분리.
- 도메인 라우터: `game-dev`, `web-dev`, `research`.
- 프로젝트 프로필: 공개 배포물에 포함하지 않음.
- 사례 기록: 범용화된 실패 조건만 테스트와 문서에 남김.

## 왜곡 위험

- 내부 상태 경로 `.psp/`가 공개 제품명으로 오해될 수 있어 README에 호환성 스키마임을 명시했다.
- 개인 개발본의 규칙을 그대로 미러링하면 개인 지식이나 지나치게 강한 규칙이 유출될 수 있어 선별 승격과 공개 표면 검사를 둔다.
- 호스트별 플러그인 설치 방식이 달라 README에서 Claude와 Codex 절차를 분리했다.

## 행동 평가

- 자동 테스트와 구조 검사는 릴리스 직전에 실행해 결과를 commit과 함께 고정한다.
- 새 세션의 Claude Code/Codex 설치·훅 실동작은 공개 원격 push 뒤 각각 검증한다.
- 검토 요청 비수정, 레퍼런스 비복제, 프로필 비누출, 원격 지식 비실행, 낡은 버전 안내 사례를 유지한다.

## 미검증

- GitHub 공개 원격에서 새로 설치하는 최종 smoke test는 첫 push 이전에는 수행할 수 없다.
- 모든 운영체제와 모든 과거 호스트 버전의 호환성을 주장하지 않는다.
