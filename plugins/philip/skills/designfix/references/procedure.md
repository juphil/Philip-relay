description: 웹/UI 디자인 수정 — 승인된 범위의 점검 결함을 고치고 실제 렌더로 재검증한다
---
$ARGUMENTS 범위의 UI 결함을 수정하라. 이 스킬은 사용자가 고치기·진행을 승인한 경우에만 쓴다. 감사만 요청됐으면 `/philip:designcheck`로 돌아간다.

1. `/philip:designcheck` 결과나 사용자 지적을 읽고 수정 대상을 고정한다. 같은 유형의 위반을 훑되 무관한 디자인 방향은 바꾸지 않는다.
2. [웹/UI 공통 매뉴얼](docs/06_web_ui_manual.md), 프로젝트 UI 프로필, 사용한 지식 leaf와 레퍼런스 모드를 확인한다.
3. 한 검수 단위씩 수정한다. 확정 UX·토큰·비율 변경이 필요하면 변경 권한을 별도로 확인한다.
4. 실제 렌더에서 대표 뷰포트와 정상·빈 데이터·로딩·오류·극단값 상태를 확인한다. 좌표·계산 스타일·대비·키보드 경로를 작업 위험에 맞게 측정한다.
5. 수정 전후 근거와 미확인 범위를 분리한다. 보지 않은 화면·기기·브라우저를 통과로 쓰지 않는다.

**보고**: 고친 항목 / 전후 수치·캡처 / 회귀 검사 / 미검증 범위. 감사에서 발견했지만 승인 범위 밖인 것은 수정하지 않고 별도 목록으로 남긴다.
