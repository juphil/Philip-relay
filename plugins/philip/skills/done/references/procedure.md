방금 끝낸 작업에 완료 사이클을 실행하라. 순서 고정, 건너뛰기 금지:

1. **정밀검토**: 변경한 코드/문서를 다시 정독 — (코드) 수명주기·실행순서·null·이벤트 구독해제 짝·GC 할당·직렬화 필드 / (문서) 낡은 표현·다른 문서와 모순. 발견 즉시 수정.
2. **검증 상태 판정**: 내가 실측(실행·관찰)까지 했는가?
   - 실측 완료 → 무엇을 어떻게 관찰했는지 1줄.
   - 실측 불가/미실시 → **"완료" 선언 금지.** 사용자가 확인할 시나리오를 구체적으로 제시("~를 실행해 ~가 보이는지")하고 결과 대기임을 명시.
3. **todo 갱신 (검증 통과분만)**: 현행 `todo/mN_*/index.md` **표 1곳**의 해당 행 상태·검증 열 갱신. 다른 파일에 상태 쓰지 말 것.
4. **변경로그**: 계획·범위가 바뀌었으면 index `## 변경로그`에 `날짜 | 무엇 | 왜` 한 줄 append. 시작 훅이 길이 축약을 알리면 현행 상태·다음 행동은 index에 남기고 오래된 상세 로그는 날짜별 `todo/archive/` 문서로 보존해 링크한다. 삭제하거나 같은 내용을 양쪽에 복제하지 않는다.
5. **inbox 처리**: `todo/_inbox.md`에 이번 작업 관련 항목 있으면 해당 phase로 이동(없으면 생략).
6. **메모리 판단**: 이번 작업에서 "다음 세션에도 유효한 새 사실"(결정+왜 / 실측 팩트 / 사용자 교정)이 생겼나? 있으면 /philip:memory 규칙대로 저장, 없으면 "저장할 것 없음" 1줄.
7. **보고**: 바뀐 것 / 검증 상태 / 남은 것 — 3줄 요약.
