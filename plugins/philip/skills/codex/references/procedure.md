현재 프로젝트에 코덱스를 적용한다. 기존 클로드 환경과 자료는 보존한다.
1. [양방향 적용 절차](docs/07_agent_bridge.md)를 전체 읽는다. 적용 요청은 이 절차의 로컬 변경 승인이다. 이미 승인된 단계는 다시 묻지 않는다.
2. `python "<플러그인 절대경로>/tools/agent_bridge.py" codex --project "<프로젝트 절대경로>"`로 변경 예정 목록을 확인한다. 명시된 메모리 경로는 `--memory "<경로>"`로 전달한다. 경로에 공백이 있어도 하나의 인자로 전달한다.
3. 충돌이 없으면 같은 명령에 `--apply`를 붙인다. 실제 `CODEX_HOME`을 사용한다. 일반 홈도 정리하려면 `--codex-home <추가 홈>`을 명시한다.
4. 대상 psp가 없거나 구버전이면 절차의 공식 CLI 설치를 실행하고 23개 스킬·훅·메모리·버전 안내·한국어 설정을 검증한다.
5. 결과·미검증 항목·백업 경로를 한국어로 보고한다. 앱의 고정 영어 버튼을 바꿨다고 말하지 않는다.
