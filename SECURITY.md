# Security Policy

Do not post tokens, personal paths, private repository content, project memory, or exploit details in a public issue.

Report non-sensitive safety problems through GitHub Issues. Use this repository's private GitHub Security Advisory reporting flow for an exposed secret or an exploitable vulnerability. Only the latest tagged version is supported.

## 한국어

공개 이슈에 토큰, 개인 경로, 비공개 저장소 내용, 프로젝트 메모리 또는 취약점 악용 세부를 올리지 마십시오.

민감하지 않은 안전 문제는 GitHub 이슈로 제보할 수 있습니다. 실제 비밀 노출이나 악용 가능한 취약점은 저장소의 GitHub Security Advisory 비공개 제보 기능을 사용해 주세요. 지원 버전은 최신 태그입니다.
